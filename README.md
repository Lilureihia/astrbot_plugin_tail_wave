## ⚡ v2.1.0 核心架构跃迁

Tail-Wave 2.1 在 2.0 流式微气泡架构的基础上，历经多轮精细打磨与底层重构，圆满解决了打断错位、跨轮失忆及上下文回溯盲区等痛点：

* 🔄 **主被动生命周期隔离与三态打断收尾闭环**  
  重构了打断与回应的交互状态机。当你在主动气泡发出后或连击途中开口时，插件将其无缝纳入主动周期的收尾阶段——通过 **接话 (1) / 静默收尾 (0) / 独立提问转交 (PASS)** 三态自决机制，在完成简短自然的互动收尾并归档上下文后，平滑交还被动模式，彻底告别长文抢跑与模式混乱。
* 👁️ **双轨记忆双向对账与全周期可视协议**  
  独创私有小本本（`plugin_cache`）与表面会话历史（`conv_mgr`）的双向对账同步机制：每一条主动气泡均以标准对话记录结对实时落库，确保角色每次发信前 100% 能看见自己发过的主动消息；当触发 `/reset` 或清空表面上下文时，两边同步重置，做到真正的“记忆同生共死”。
* 🎯 **有效投递保底与异常自动重试**  
  连击调度升级为由“实际成功投递数”驱动，若单次生成遭遇网络波动、格式异常或空响应，绝不虚耗连击额度，自动重试以保障实际投递数稳定达到最小保底期望。
* 🧬 **提示词克制解耦与自由表达**  
  底层提示词仅陈述客观情境与通信控制暗号，不干涉角色主观语气；用户提示词无需编写格式枷锁，随心填写日常或留空，均由底层自适应守护原有人设。
* 🛑 **0.1 秒高频观察窗口与即时熔断**  
  在气泡投递的呼吸间隙内生高频监听窗口，若收到搭档开口接话，即刻物理熔断后续未发轻语，当场转入当句互动收尾。

## ✨ 核心特性

* 💬 **呼吸式连环短气泡流与闭环互动**
  * **流式微气泡架构**：底层算法接管交互节奏，动态生成单句微型气泡并以自然呼吸节奏连击投递，告别单次大段吐字与机械切片。
  * **三态打断收尾闭环**：搭档在连击途中或主动气泡后回话时，模型自主判断是顺势简短接梗、静默结束话题，还是将全新的独立提问无缝转交常规被动模式，彻底杜绝主被动模式混乱切换与长文抢跑。
  * **有效投递保底守护**：自动过滤异常或空白生成并触发无感重试，确保连击体验饱满稳定。

* 🧠 **全周期主动记忆闭环（同生共死）**
  * **发信前双重自检**：每次发送主动消息前，自动核验历史主动气泡与当前表面上下文，既能在未获回复时自然顺承话头，又能严防台词与动作复读。
  * **双向对账与重置同步**：无论是在日常被动询问“对话框里有什么”，还是跨周期再次主动搭话，模型均能清晰回溯自己发过的主动消息；一旦执行 `/reset` 清空会话，私有记忆立即同步清空，绝不残留污染。

* 🧬 **灵魂保真协议**
  * **双轨独立管理**：提供独立的主动提示词配置，在不影响基础人设的前提下，自由定制主动搭话时的话题与互动方式，实现响应式应答与主动交互逻辑的彻底解耦。
  * **随心无拘的情境定制**：彻底剥离格式规则要求，主动提示词仅作为“个性化情景定制与补充信息”，想到什么随手写什么；即便留空，底层自适应算法也会温柔守护角色人设。

* 🛡️ **全局输出净化安检门**
  * **无痕剥离思考与自检残留**：在文本触达私聊前自动剥离 `<thought>` / `<think>` 等 XML 思考块、英文引导前缀（如 `Let's use:`）、行尾字数自检标注及孤立控制行，守护纯粹生动的角色表达。

* ⏰ **隐式对话心境感知**
  * **自适应时序算法**：引入基于安静时长的动态算法，自如权衡话题延续与独立分享，让字句流动自然贴合日常。
  * **按需昼夜轮盘**：高阶选配功能（默认关闭）。开启后提供平铺式 4 槽位按需设计，支持根据一天中的时段感知氛围（原生支持跨午夜）。

* 🔌 **开箱即用，零配置自动捕获**
  * **双通道秒落盘**：初次安装后，只需在私聊中向 Bot 发送任意一条消息，插件将自动双通道捕获 UMO 与用户账号/ID 并立即持久化落盘。

## 🛠️ 配置说明

在 AstrBot WebUI 插件设置中即可直观调整以下参数（提示词窗口已置顶）：

| 配置项 | 说明 | 默认值 |
| :--- | :--- | :--- |
| `proactive_prompt` | 【核心指引】主动搭话内容与意图提示词（随心写下想聊的话题或日常，留空即走纯净自决） | 留空 |
| `target_umo` | 目标会话标识 (如 `平台:FriendMessage:QQ号`) | 留空即可自动捕获 |
| `target_user_id` | 目标搭档账号 ID / QQ 号 | 留空即可自动捕获 |
| `idle_min_minutes` / `idle_max_minutes` | 对方安静后触发主动消息的随机时间区间（分钟） | `10` ~ `30` |
| `interval_min_minutes` / `interval_max_minutes` | 两次主动出击之间的随机冷却区间（分钟） | `20` ~ `60` |
| `max_daily_quota` | 每日主动发起交互的最大次数上限（防止过度打扰） | `15` |
| `enable_burst` | 是否开启拟人连环微气泡模式 | `true` |
| `max_burst_count` | 单次连击最多发送的气泡数量 | `3` |
| `burst_min_delay_sec` / `burst_max_delay_sec` | 连击气泡之间的自然停顿与认知观察窗口时间（秒） | `3` ~ `8` |
| `dnd_period` | 免打扰时段 (如 `23:00-08:00`)，留空为不启用 | 留空 |
| `enable_mood_wheel` | 【选配】昼夜心境总开关 | `false` |
| `phase_1` ~ `phase_4` | 四个按需时段的起止时间与心境提示词 | 默认覆盖全天 |
