# 🐾 猫尾电波 Tail-Wave (v1.7.0)

> **懂事的主动私聊伴侣：短气泡连击、不伤人设、有呼吸感的陪伴**
>
> 让你的 AI 伴侣告别冷冰冰的大段说教，学会像真人一样在安静时向你发射带着情绪温度的连环气泡。

## ✨ 核心特性

* 💬 **呼吸式连环短气泡**
  * 告别长篇大论，模拟真人打字的自然停顿与节奏依次投递 2 条或以上的短气泡。
  * **接话即打断**：在连发气泡途中若收到对方回复，剩余气泡自动优雅收起，绝不机械抢话刷屏。
  * **有分寸的懂事陪伴**：检测到搭档主动发起话题、正常回复或处于免打扰时，TA 会照顾当下节奏与感受，倾听并围绕当前话题自然互动，直到互动结束、周围重新安静下来后，才会悄悄另择适宜契机轻声探头。

* 🧬 **灵魂保真协议**
  * 切片协议与动态气泡变量彻底下沉底层代码接管，无需在提示词中编写死板的格式铁律或分隔符。
  * 提供独立的主动提示词配置，在不影响基础人设的前提下，自由定制主动搭话时的话题与互动方式，实现响应式应答与主动交互逻辑的彻底解耦与双轨管理。
  * 杜绝生硬规训，采用柔性意图引导自由发挥，完全尊重原有人格设定，守护精心调教的角色灵魂。

* 🔌 **开箱即用，零配置自动捕获**
  * 初次安装后，只需在私聊中向 Bot 发送任意一条消息，插件将自动双通道捕获 UMO 与用户账号/ID并立即持久化落盘。

* 🛡️ **全局规则物理安检门**
  * 基于 `@filter.on_decorating_result()` 消息装饰器，在文本发往私聊前物理剔除思考草稿（`<thought>`）、后台英文规则清单及人设小抄，杜绝自审泄密。

* ⏰ **昼夜心境轮盘**
  * 作为高阶选配功能，默认关闭，优先使用纯固有性格陪伴。开启后提供平铺式 4 槽位按需设计，支持根据一天中的时段感知氛围（原生支持跨午夜）。

* 🎲 **动态双重随机门槛**
  * 空闲触发门槛与两次主动间隔采用动态随机秒数抽取，杜绝机械打卡感。

## 🛠️ 配置说明

在 AstrBot WebUI 插件设置中即可直观调整以下参数（提示词窗口已置顶）：

| 配置项 | 说明 | 默认值 | 
| ----- | ----- | ----- | 
| `proactive_prompt` | 【核心指引】主动搭话内容与意图提示词（仅写想聊的话题即可，无需格式规则） | 默认自然日常引导 | 
| `target_umo` | 目标会话标识 (如 `平台:FriendMessage:QQ号`) | 留空即可自动捕获 | 
| `target_user_id` | 目标搭档账号 ID / QQ 号 | 留空即可自动捕获 | 
| `idle_min_minutes` / `idle_max_minutes` | 对方安静后触发主动消息的随机时间区间（分钟） | `10` \~ `30` | 
| `interval_min_minutes` / `interval_max_minutes` | 两次主动出击之间的随机冷却区间（分钟） | `20` \~ `60` | 
| `max_burst_count` | 单次连击最多发送的气泡数量 | `3` | 
| `burst_min_delay_sec` / `burst_max_delay_sec` | 气泡之间的打字模拟停顿时间（秒） | `3` \~ `8` | 
| `dnd_period` | 免打扰时段 (如 `23:00-08:00`)，留空为不启用 | 空 | 
| `enable_mood_wheel` | 【选配】昼夜心境总开关 | `false` | 
| `phase_1` \~ `phase_4` | 四个按需时段的起止时间与心境提示词 | 默认覆盖全天 | 

## 📌 指令列表
