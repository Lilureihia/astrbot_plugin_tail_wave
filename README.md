## ⚡ v2.0.0 核心架构跃迁

Tail-Wave 2.0 经历了从底层通信逻辑到交互状态机的全面重构，告别传统被动切片，**全面升级为逐句发送的流式微气泡**：

* 🚀 **通信架构升维**  
  废弃粗暴的文本后置截断与固定正则拆分，底层采用全异步流式调度方案，使消息调度本身即具备自然的对话节律与呼吸停顿。

* 🧬 **提示词自由表达**  
  无需编写任何格式枷锁，随心填写想聊的话题或日常琐事；即便留空，底层自适应算法也会温柔守护着TA的原有人设。

* 🛑 **认知与思考观察窗口**  
  在气泡投递的呼吸间隙内生了认知与观察思考，若收到搭档开口接话，即刻自然收起后续轻语，无缝转入专注倾听。

* 🛡️ **深层语义通道安检**  
  引入深层语义识别通道，针对主动消息进行意图级感知与无痕剥离，在不伤及正文的前提下剔除思考草稿与潜在小抄。

* 🌌 **自适应语境延续天平**  
  基于安静时长的流转算法，在承接上一轮话题余温与自发开启全新日常之间，实现自然自如的平衡。

## ✨ 核心特性

* 💬 **呼吸式连环短气泡流**

  * **流式微气泡架构**  
    底层算法接管交互节奏，动态生成单句微型气泡并以自然呼吸节奏连击投递，彻底告别单次大段吐字与机械切片。

  * **认知与思考观察窗口**  
    将气泡投递间隙升格为兼具实时观察与认知思考的双向窗口。在精准感知搭档状态的同时，一旦收到接话即刻收起未发轻语，无缝切换为专注倾听。

  * **懂倾听的有分寸陪伴**  
    检测到搭档主动发起话题、正常回复或处于免打扰时，TA 会照顾当下节奏与感受，倾听并围绕当前话题自然互动，直到互动结束、周围重新安静下来后，才会悄悄另择适宜契机轻声探头。

* 🧬 **灵魂保真协议**

  * **双轨独立管理**  
    提供独立的主动提示词配置，在不影响基础人设的前提下，自由定制主动搭话时的话题与互动方式，实现响应式应答与主动交互逻辑的彻底解耦。

  * **随心无拘的情境定制**  
    彻底剥离格式规则要求，主动提示词仅作为“个性化情景定制与补充信息”，想到什么随手写什么；即便留空不填，底层自适应算法也会温柔守护着TA的原有人设。

  * **守护角色灵魂**  
    杜绝生硬规训，采用柔性意图引导自由发挥，完全尊重原有人格设定，守护精心调教的角色灵魂。

* 🛡️ **全局规则物理安检门**

  * **深层语义识别通道**  
    脱离表层死板规则，针对主动发信引入深层语义通道，不仅能识别人为约定的格式特征，更能精准感知深层思维草稿与隐藏大纲。

  * **无痕剥离与零误伤防护**  
    在主动文本真正触达私聊前执行静默净化，将后台思考过程与潜在小抄无痕剥离，即使正文中含有相似语气或特殊断句也绝不误伤，守护最纯粹的角色表达。

* ⏰ **隐式对话心境感知**

  * **自适应时序算法**  
    引入基于安静时长的动态算法，自如权衡话题延续与独立分享，让字句流动自然贴合日常。

  * **按需昼夜轮盘**  
    作为高阶选配功能，默认关闭。开启后提供平铺式 4 槽位按需设计，支持根据一天中的时段感知氛围（原生支持跨午夜）。

* 🔌 **开箱即用，零配置自动捕获**

  * **双通道秒落盘**  
    初次安装后，只需在私聊中向 Bot 发送任意一条消息，插件将自动双通道捕获 UMO 与用户账号/ID 并立即持久化落盘。

## 🛠️ 配置说明

在 AstrBot WebUI 插件设置中即可直观调整以下参数（提示词窗口已置顶）：

| 配置项 | 说明 | 默认值 | 
| ----- | ----- | ----- | 
| `proactive_prompt` | 【核心指引】主动搭话内容与意图提示词（随心写下想聊的话题或日常，无需写格式规则，留空亦可） | 默认自然日常引导 | 
| `target_umo` | 目标会话标识 (如 `平台:FriendMessage:QQ号`) | 留空即可自动捕获 | 
| `target_user_id` | 目标搭档账号 ID / QQ 号 | 留空即可自动捕获 | 
| `idle_min_minutes` / `idle_max_minutes` | 对方安静后触发主动消息的随机时间区间（分钟） | `10` \~ `30` | 
| `interval_min_minutes` / `interval_max_minutes` | 两次主动出击之间的随机冷却区间（分钟） | `20` \~ `60` | 
| `max_burst_count` | 单次连击最多发送的气泡数量 | `3` | 
| `burst_min_delay_sec` / `burst_max_delay_sec` | 连击气泡之间的自然停顿与认知观察窗口时间（秒） | `3` \~ `8` | 
| `dnd_period` | 免打扰时段 (如 `23:00-08:00`)，留空为不启用 | 空 | 
| `enable_mood_wheel` | 【选配】昼夜心境总开关 | `false` | 
| `phase_1` \~ `phase_4` | 四个按需时段的起止时间与心境提示词 | 默认覆盖全天 |
